🚀 COMO COMEÇAR (PRÓXIMOS PASSOS)

  PASSO 1: Instalar Dependências
  ────────────────────────────────────────────────────────────────────────
  
  Você PRECISA ter instalado:
    ✅ Java JDK 21+ (check: java -version)
    ✅ Maven 3.9+ (check: mvn --version)
  
  Se não tem Maven, siga: SETUP.md
  
  
  PASSO 2: Compilar o Projeto
  ────────────────────────────────────────────────────────────────────────
  
  CD para o diretório:
    cd e:\Diego\TCC\poc-api
  
  Compile:
    mvn clean install
  
  ⏱️ Tempo: ~2 minutos (primeira vez, download de dependências)
  
  
  PASSO 3: Executar a Aplicação
  ────────────────────────────────────────────────────────────────────────
  
  Execute:
    mvn spring-boot:run
  
  ✅ Sucesso quando ver:
    "Started PocApiApplication in X seconds"
  
  🌐 Aplicação rodando em:
    http://localhost:8080/api
  
  
  PASSO 4: Testar os Endpoints
  ────────────────────────────────────────────────────────────────────────
  
  Abra OUTRO TERMINAL e teste:
  
    # Listar autores (deve retornar 2 autores pré-carregados)
    curl http://localhost:8080/api/authors
    
    # Criar novo autor
    curl -X POST http://localhost:8080/api/authors ^
      -H "Content-Type: application/json" ^
      -d "{\"name\":\"Isaac Asimov\",\"email\":\"asimov@example.com\"}"
    
    # Listar livros
    curl http://localhost:8080/api/books
    
    # Listar reviews
    curl http://localhost:8080/api/reviews
  
  
  PASSO 5: Executar Testes
  ────────────────────────────────────────────────────────────────────────
  
    # Todos os testes
    mvn test
    
    # Apenas testes unitários
    mvn test -Dtest=*ServiceTest
    
    # Apenas testes de integração
    mvn test -Dtest=*IntegrationTest
    
    # Com cobertura de código
    mvn clean test jacoco:report
    
    Relatório em: target/site/jacoco/index.html

📡 ENDPOINTS DA API

  AUTHORS:
  ├── GET    /api/authors             (listar todos)
  ├── GET    /api/authors/{id}        (buscar por ID)
  ├── POST   /api/authors             (criar)
  ├── PUT    /api/authors/{id}        (atualizar)
  └── DELETE /api/authors/{id}        (deletar)
  
  BOOKS:
  ├── GET    /api/books               (listar todos)
  ├── GET    /api/books/{id}          (buscar por ID)
  ├── GET    /api/books/by-author/{authorId}  (livros do autor)
  ├── POST   /api/books               (criar)
  ├── PUT    /api/books/{id}          (atualizar)
  └── DELETE /api/books/{id}          (deletar)
  
  REVIEWS:
  ├── GET    /api/reviews             (listar todos)
  ├── GET    /api/reviews/{id}        (buscar por ID)
  ├── GET    /api/reviews/by-book/{bookId}  (reviews do livro)
  ├── POST   /api/reviews             (criar)
  ├── PUT    /api/reviews/{id}        (atualizar)
  └── DELETE /api/reviews/{id}        (deletar)

🎯 ENTIDADES

  Author (Autor)
  ├── id: Long (auto-gerado)
  ├── name: String (obrigatório)
  └── email: String (obrigatório, único)
  
  Book (Livro)
  ├── id: Long (auto-gerado)
  ├── title: String (obrigatório)
  ├── isbn: String (obrigatório, único)
  └── author_id: Long (referência a Author)
  
  Review (Resenha)
  ├── id: Long (auto-gerado)
  ├── rating: Integer (1-5, obrigatório)
  ├── content: String (opcional)
  └── book_id: Long (referência a Book)

🛠️ TROUBLESHOOTING

  ❌ "mvn: command not found"
     ❓ Solução: Maven não está instalado. Ver SETUP.md
  
  ❌ "JAVA_HOME is not set"
     ❓ Solução: Instalar JDK 21+ e configurar variável de ambiente
  
  ❌ "Port 8080 already in use"
     ❓ Solução: Mudar port em src/main/resources/application.properties
                 server.port=8081
  
  ❌ "Tests failing"
     ❓ Solução: Executar: mvn clean test -e (mostra stack trace)
  
  ❓ Outras dúvidas?
     👉 Ver arquivos README.md ou SETUP.md

💡 DICA IMPORTANTE: SNAPSHOTS

  Os testes de integração usam ApprovalTests (snapshot testing).
  
  Primeira execução:
    1. Cria arquivos .received.txt com as respostas
    2. Compare com o esperado
    3. Copie .received.txt → .approved.txt para "aprovar"
  
  Próximas execuções:
    - Compara automaticamente contra .approved.txt
    - Se mudou, falha o teste e mostra a diferença
  
  Maior segurança para regressões de API!
